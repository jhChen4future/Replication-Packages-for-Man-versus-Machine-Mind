# Working paper

This directory contains the manuscript associated with **Strategic
De-socialization**.

## Available file

[`Writing_sample_latest.pdf`](./Writing_sample_latest.pdf) is the latest
manuscript currently archived in this repository. Its title page retains the
earlier project title:

> *Humans versus Machine Mind: Bias and Strategic Adaptation in Human
> Interactions with AI*

The repository and personal project page now use **Strategic De-socialization:
Experimental Evidence on Human Interaction with Large Language Models** as the
public-facing title. The PDF has been preserved as an archival manuscript rather
than edited in place without its original Word source.

## Status

This is a working paper, not a journal publication. The manuscript used an
[American Economic Association template](https://www.aeaweb.org/journals/templates)
for Word-formatting convenience only. That does not indicate submission to,
review by, acceptance at, or endorsement by an AEA journal.

Before citing individual estimates, read the
[research-status and limitations notice](../README.md#important-research-status-and-known-limitations).
In particular:

- the main experiment uses a fixed game order;
- the Trust and Ultimatum Game cells are small and exploratory;
- repeated Prisoner's Dilemma rounds provide many observations but not many
  independent participants;
- the auxiliary belief and social-preference estimates are not considered
  reliable structural results;
- data collection ended because redesign costs, comprehension problems, model
  uncertainty, and remaining funding made continuation under the same protocol
  unjustified; and
- rapid changes in frontier model capabilities limit generalization from one or
  two historical model snapshots.
